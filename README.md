# Project Overview
This project used MLFlow and Pyspark to read in a credit card default dataset to predict if a customer will default on their next payment. The Default of Credit Card Clients Dataset is used for this project, and can be found from the UC Irvine Machine Learning library. The project compares a simple baseline model to three model types. These types include Logistic Regression, Random Forest, and Decision Tree. The conclusion was that the Decision Tree provided the most improvement compared to the baseline, obtaining an AUC of 0.772 compared to the baseline's AUC of 0.5.
